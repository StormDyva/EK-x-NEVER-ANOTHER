# Never Another – Android App PoC

Dette projekt er udviklet som et eksamensprojekt på 2. semester IT-Arkitektur.  
Formålet er at udvikle et proof of concept på et forbedret mobilt købsflow for virksomheden Never Another.

## Teknologier

Projektet er udviklet med:

- Kotlin
- Android Studio
- Jetpack Compose
- MVVM arkitektur
- Git & GitHub
